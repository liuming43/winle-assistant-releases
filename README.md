# 玩乐车工厂调试助手

面向 Windows 10 / 11 的 CAN / LIN 无线调试助手。

## 下载与安装

[前往最新版下载页面](https://github.com/liuming43/winle-assistant-releases/releases/latest)

在页面的 Assets（资源）中下载 `WinLeAssistant-版本-Setup.exe`，双击安装即可。下载不需要 GitHub 账号。

## 软件内更新

从 0.2.1 起，更新地址已内置。进入“设置与帮助 → 软件更新”，点击“检查更新”，发现新版后点击“立即更新”。软件会下载、校验、覆盖安装并重新打开，本地采集记录会保留。

更新前请停止记录和设备连接。仍在使用 0.1.0 或 0.2.0 的用户，需要手动安装一次 0.2.1 或后续版本。

## 设备使用

给设备供电，按设备说明配置 Wi-Fi，在软件里点击“连接设备”。收到板端确认后即可查看 CAN / LIN 报文，按需开始记录。

本仓库仅发布安装包及版本说明，不包含软件源码。当前为产品预览版。
